# Security Policy

## Scope

NetScope is an educational and portfolio-oriented networking diagnostics project.

It is intended for use in networks, hosts and systems that the user owns or is explicitly authorized to test.

## Current Diagnostic Scope

The current implementation provides:

- IPv4/CIDR analysis
- subnet comparison
- DNS resolution
- explicit TCP connectivity checks
- local network-interface inspection
- traffic-counter visualization
- conceptual topology visualization

## Responsible Use

Users should only perform diagnostics against systems for which they have appropriate authorization.

## Out of Scope

The current project does not implement:

- password attacks
- credential harvesting
- malware
- persistence
- exploit delivery
- unauthorized access
- arbitrary remote command execution
- automated Internet-wide scanning

## Future Security Features

Future security-oriented development may explore:

- network segmentation
- security-event modelling
- anomaly detection
- controlled protocol analysis

All future security functionality should remain within authorized and controlled environments.

## Reporting

Potential security issues can be reported through the repository's GitHub issue/security mechanisms.
