# NetScope roadmap

## Stage 1 — Current portfolio baseline
- IPv4/CIDR analysis
- subnet comparison
- DNS lookup
- TCP connectivity check
- local interface inventory
- visualizations
- unit tests

## Stage 2 — Networking depth
- DHCP lease simulator
- routing-table parser
- VLAN/802.1Q configuration model
- IPv6 address calculator
- ICMP reachability through safe local diagnostics

## Stage 3 — Observability
- time-series interface metrics
- CSV/SQLite historical storage
- threshold alerts
- structured JSON logs
- packet-capture import using `.pcap`/`.pcapng` supplied by the user

## Stage 4 — Professional operations
- FastAPI service layer
- role-based access model for a multi-user lab
- Docker packaging
- CI with GitHub Actions
- automated quality checks and documentation build
